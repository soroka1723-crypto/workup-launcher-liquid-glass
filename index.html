Возможности

Liquid Glass UI

Прозрачная стеклянная карточка, мягкие блики, акценты и компактная компоновка без выхода за экран.

Автоустановка

Загрузка версии, библиотек, assets, Fabric Loader и модов с прогрессом и логом.

Удобные настройки

Выбор RAM, сохранение ника, открытие папки игры, копирование/очистка лога, валидация ввода.

Запуск

  1. Скачайте релиз (JAR или app-image EXE) со страницы Releases.
  2. Для app-image: распакуйте папку целиком и запустите WorkupLauncher.exe (рядом должны быть app/ и runtime/).
  3. Для JAR: установите Java 21 и запустите java -jar workup-launcher.jar.
  4. Введите ник, выберите RAM и нажмите Запуск.
